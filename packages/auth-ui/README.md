# @engenty/auth-ui

Authentication UI, Supabase session helpers, and public auth routes.

**Documentation:** [packages/auth-ui/docs/README.md](./docs/README.md) (published under `/docs/dev/packages/auth-ui/` on the docs site).

**UI plugin manifest:** `engenty.plugin.json` is required for catalog discovery. This repo does not use `plugins.json`.

## Quick reference

- `src/plugin.tsx` — `@engenty/auth-ui/plugin`
- `src/index.ts` — session API + page exports
- `engenty.plugin.json` — UI entry for `apps/ui` generated catalog

See the [package docs](./docs/README.md) for architecture, routes, and session helpers.
