# @engenty/app-shell

Product app shell layout and browser-owned Agent UI state.

**Documentation:** [packages/app-shell/docs/README.md](./docs/README.md) (published under `/docs/dev/packages/app-shell/` on the docs site).

## Quick reference

- `src/components/app-layout/` — layout frame and secondary-nav modules
- `src/components/` — `app-sidebar`, `app-topbar`
- `src/context/` — copilot shell, agent UI state, secondary nav
- `src/navigation.ts` — `@engenty/app-shell/navigation` entry
- `src/index.ts` — main package exports

See the [package docs](./docs/README.md) for architecture, shell layout, navigation, and Agent UI registration.
