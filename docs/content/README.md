# Engenty Documentation

Engenty is an open-source platform for embedding AI copilots and agents into your
application, with a plugin architecture for shipping your own modules.

## Where to start

- **[User Guide](/user)** — using Engenty day to day: the copilot, agents, and modules.
- **[Installation](/setup)** — install and deploy your own Engenty instance.
- **[Developer Docs](/dev)** — architecture, the plugin system, building modules, and running it locally.
- **[Roadmap](/roadmap)** — what we're building next.

> This documentation is the published, user-facing set. Internal planning and
> draft notes live outside the site and are not part of the release.
