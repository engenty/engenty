# Engenty Documentation

Engenty is a Fair Source platform for embedding AI copilots and agents into your
application, with a plugin architecture for shipping your own modules. The source
is public and free to self-host under [FSL-1.1-MIT](https://fsl.software) — it is
not OSI open source.

## Where to start

- **[User Guide](/docs/user/README)** — using Engenty day to day: the copilot, agents, and modules.
- **[Installation](/docs/setup/README)** — install and deploy your own Engenty instance.
- **[Developer Docs](/docs/dev/README)** — architecture, the plugin system, building modules, and running it locally.
- **[Roadmap](/docs/roadmap/README)** — what we're building next.
