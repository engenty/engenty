# Choosing effort

Some questions need a quick answer. Others deserve real thought. Engenty lets
you say which, without asking you to know anything about AI models.

You'll find the effort control in the composer, next to where you type.

## The three levels

| Level | Good for |
| --- | --- |
| **Low** | Short questions, quick lookups, reformatting, simple edits. Fastest and cheapest. |
| **Medium** | Everyday work — drafting, summarising, answering questions about your data. The sensible default. |
| **High** | Hard problems: multi-step reasoning, tricky analysis, anything you'd want a colleague to slow down and think about. |

Your choice sticks for the conversation, so you can set it once and keep
working. Change it at any point — the next message uses the new level.

There's also **Auto**, which leaves the decision to Engenty and uses your
workspace's standard setting.

## Which level should I use?

Start at medium. Move up when an answer feels shallow or a task has several
steps that depend on each other. Move down when you're doing something
mechanical and want it fast.

Higher effort costs more and takes longer. It isn't better at everything — for
a simple lookup, high effort mostly just makes you wait.

## If a level isn't available

Your plan decides which levels you can use. If you pick one your plan doesn't
include, Engenty uses the highest level you *are* entitled to and carries on —
your request still gets answered. Levels outside your plan appear greyed out.

If you need a level your plan doesn't cover, ask your workspace admin.

## Picking a specific model

If you know exactly which model you want, turn on **Expert: choose a model** in
the effort menu. That reveals the full model picker, and your choice overrides
the effort level until you turn expert mode off again.

Most people never need this. It's there for self-hosted installations and for
comparing models directly.

## Agents and tasks

Agents use the same idea. When you configure an agent, you set the effort it
should work at rather than naming a model — so an agent that does careful
review can sit at high effort while one that files and sorts sits at low.

Your workspace admin can see and change these under **Settings → AI**.
