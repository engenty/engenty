# Installation

This section walks you through standing up your own Engenty instance — from a
fresh clone of the repository to a running app on your own server.

## Deployment guides

- **[VPS deployment with Coolify](/setup/coolify)** — deploy the full stack to a
  VPS managed by [Coolify](https://coolify.io/), behind a single HTTPS domain.

## What you'll need

Before you start, it helps to have:

- A **VPS** (a small cloud server) with Docker installed.
- A **domain name** you control, pointed at that server.
- A **Supabase** project (self-hosted or cloud) for the database and auth.
- API keys for the AI provider you want to use.

Each guide lists its exact prerequisites at the top. If you just want to try
Engenty locally first, see the **[Developer → Local development](/dev/local-development)**
guide instead.
