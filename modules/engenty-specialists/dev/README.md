# engenty-specialists — dev notes

Design notes for hired engenties. The canonical work model (Routine, Run,
Task, Workflow) is `docs/content/dev/work-model.md`; these notes cover what a
maintainer of this module needs on top of it.

- [floor-and-gating.md](./floor-and-gating.md) — what every specialist
  carries, what rides with which skill, and why the constants live in
  ai-core while this module is the entry.
- [routine-approval.md](./routine-approval.md) — when `routines_create`
  needs a person, how the card publishes, and the runs that cannot park.
- [hire-dialog.md](./hire-dialog.md) — how the Space hire wizard maps a
  draft (character, name, description, template) onto a registry row.
- [module-plan.md](./module-plan.md) — the plan that created this module,
  with the decisions taken. History, not guidance.
